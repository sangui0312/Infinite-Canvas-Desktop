## Agent 生成节点

- 批准计划后立即创建占位节点，显示任务标题、等待状态、生成动画和耗时。
- 生成结果填回原节点，刷新、恢复、停止后继续和失败重试复用已有节点。
- 保留生成期间的手动移动、改名和尺寸调整。删除节点后的成果保存在任务记录中。
- 节点可直接打开对应的 Agent 任务。结果按实际图片比例适配，手动调整过的尺寸继续保留。

## 图片命名与下载

- Agent 图片使用批准计划中的任务标题命名，画布标签和成果列表同步显示。
- 下载支持 Agent 命名、原始文件名和自定义重命名，覆盖单张、ZIP 和逐张下载。
- 已有 Agent 成果自动补齐名称，保留手动图片命名。批量下载自动处理重名文件，保留真实格式后缀。

## 安装和更新

- Windows x64 安装包为 `InfiniteCanvas-Desktop-1.1.3-x64.exe`。
- 兼容的 1.1.0、1.1.1、1.1.2 使用分别匹配自身版本的功能更新包。
- 其他基础版本通过安装包升级，更新保留个人数据和自定义存储位置。
