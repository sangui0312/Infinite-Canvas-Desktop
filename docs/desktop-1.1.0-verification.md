# 1.1.0 发布验证

本版包含素材生命周期、回收站与默认关闭的自动清理，以及个人资料迁移缓存占用修复。

- 80 项 Node 检查、125 项集成 Python 检查通过，无跳过。
- 素材功能真实 Chromium 联动通过：设置开关、引用扫描、观察期、保护、回收站恢复、撤销及两种画布会话。
- 独立复核发现的重复 URL 多条资产记录恢复遗漏已修复，选择性恢复及永久移除条目不影响共享文件的复测通过。
- 完整安装包窗口检查通过，版本 1.1.0；普通/智能画布保存重开、节点添加与连线、API 设置、旧 Web 导入、数据存储、下载、更新 UI、合成更新失败回滚及个人资料保留均通过。
- 安装包媒体检查通过：上传、视频 Range 206、混合 ZIP、PSD、画布导入和项目导出。
- 34 项必需资源与源码字节一致，3336 个打包文件未发现禁止的私有目录、环境密钥、缓存及日志；原 Web 来源记录的 152 个文件未改变。
- 1.0.1、1.0.0、0.3.7、0.3.0 客户端均选择安装包更新，差分下载开启；安装包 SHA-512 与 latest.yml 匹配，公告一致。

本版修改桌面基础组件，使用严格基础文件校验构建，清单为 installer 模式，没有文件补丁。minimumShell 为 1.1.0，新的 release-tree 基线用于后续兼容更新。升级保留个人数据，自动清理不自动开启。

测试使用隔离数据。没有清理真实素材、覆盖用户安装或调用付费生成；30 天规则使用可控时钟验证，实际差分下载比例取决于缓存及网络。

发布先建立 GitHub 草稿，核对 7 个附件的大小和 SHA-256 后公开，再验证匿名清单下载和安装器 Range 请求。公开结果另存于工作区发布记录。
