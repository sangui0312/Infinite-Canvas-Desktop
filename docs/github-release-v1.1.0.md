## 1.1.0

- 新增素材清理与回收站，在“更多设置 → 数据存储”中查看。自动清理默认关闭；开启后，受管图片、视频连续未引用 30 天才移入回收站，默认再保留 7 天。
- 扫描预览显示引用位置和保护状态，支持取消、分页及“始终保留”。画布及回收站、聊天和生成历史、资产库、工作流、Agent、撤销记录及运行任务共同保护素材。
- 删除节点仍可撤销；素材删除统一经过引用检查和回收站。共享文件保留，被移除的资产条目可单独恢复，同文件多条记录也可选择性恢复。
- 素材移动、重命名保留旧地址兼容；未变化的大视频不重复完整哈希，新大文件扫描可取消。
- 修复个人数据迁移被 GPU 缓存占用阻断的问题，迁移完成前使用独立浏览器会话目录，跳过可重建缓存，保留个人资料复制校验和失败回退。

## 升级说明

本次包含桌面基础组件改动，使用安装包更新，不发布旧版本文件补丁。软件内优先尝试安装包差分下载，不可用时回退完整下载；升级保留个人数据和自定义存储位置。

也可以下载 `InfiniteCanvas-Desktop-1.1.0-x64.exe`，退出旧版后覆盖原安装目录。升级后自动清理仍默认关闭；首次启用从完整确认未引用时开始观察，不按旧文件创建时间立即删除。

外部原文件、共享或自定义素材目录、程序配置及备份不自动清理；音频、文档暂不纳入自动删除。移入同盘回收站不会立即释放空间，永久删除后才释放。

附件提供完整安装器、blockmap、更新清单、发布基线及 `SHA256SUMS.txt`。

验证：80 项桌面检查、125 项后端检查、最终安装包窗口与媒体流程检查通过。未调用付费模型，未对真实个人资料执行清理。
