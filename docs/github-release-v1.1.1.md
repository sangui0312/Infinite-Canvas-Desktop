## MiniMax 视频适配与手动升至 2K

- 修复 **MiniMax-H3-Max**：5～15 秒，480P/768P/1080P；支持合法的参考图、视频、音频组合，1080P 正确省略水印。
- 两种画布按模型显示可用参数，首尾帧跟随输入比例，补齐实际视频尺寸与比例异常提示。
- **H3 768P 结果新增“升至 2K”**：先查看原片，确认额外计费后升级；保留 768P，2K 单独保存并显示进度。H3-Max 不会误调用再生成。
- 升级任务保存、去重和恢复；查询或下载失败复用已有任务，提交结果不明时停止自动重提。
- Agent 接入 H3-Max，保留视频原任务信息，修复智能画布保存期间升级进度及成果衔接。

## 下载与升级

- 新安装：下载 `InfiniteCanvas-Desktop-1.1.1-x64.exe`。
- 已有安装：在软件中检查更新，兼容的 1.1.0 使用文件更新包；基础不兼容的旧版本自动选择安装包。
- 升级保留个人数据和自定义存放位置，素材自动清理不会因升级而自动开启。
- Regeneration 是额外计费任务，原参考素材也可能再次计费；仅适用于同账号成功的 MiniMax-H3 768P 结果。

本次校验使用隔离数据与模拟生成接口，未调用真实付费生成。
