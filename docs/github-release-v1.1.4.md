## 宫格切分

- 修复普通画布宫格切分粗线在系统和界面缩放下的位置偏移，切分线固定在图片范围内，预览位置与实际切分一致。
- 智能画布补齐相同的粗线预览，支持预设、自定义切分和拖动调整；切换裁剪或宫格拼接时清除切分线。
- 切分间隔按原图像素换算，支持图片任意缩放、滚动与窗口尺寸变化，导出结果保留原图内容。

## 安装和更新

- Windows x64 安装包为 `InfiniteCanvas-Desktop-1.1.4-x64.exe`。
- 兼容的 1.1.0、1.1.1、1.1.2、1.1.3 使用分别匹配自身版本的功能更新包。
- 其他基础版本通过安装包升级，保留个人数据和自定义存储位置。
