## 1.0.1

- 优化 3D 导演台：对象列表、预览和属性三栏布局，支持明暗主题与小窗口；修复缩放，增加旋转、平移、取景范围和视角重置。
- 增加对象复制删除、白块尺寸编辑、走位及镜头关键帧轨道、关键帧拖动删除、独立撤销重做与播放快捷键。
- PNG/WebM 导出显示进度、支持取消，完善编码器错误提示与资源释放，兼容已有预演数据。
- 删除 RunningHub、火山引擎的内置平台适配、专属接口及界面代码；历史成果保留，不会静默切换生成平台。
- 软件内更新公告改为按版本号分组，保留历史记录。

## 更新方式

本次同时修改了旧版文件补丁无法覆盖的 Photoshop 连接器，使用安装包更新，优先尝试差分下载；不可用时下载完整安装包。为避免保留旧代码，本版不发布程序文件补丁。后续基础文件兼容的同主版本更新继续提供多基线补丁。

可在软件内检查更新，或下载 `InfiniteCanvas-Desktop-1.0.1-x64.exe`，退出旧版后覆盖原安装目录。升级保留个人数据与自定义存储位置；0.x 用户也使用该完整安装包。

`SHA256SUMS.txt` 提供附件 SHA-256 校验值，`release-tree.json` 保存本版发布基线。

验证：64 项前端与桌面检查、84 项后端检查、打包窗口和媒体流程检查通过。未调用付费模型，未在用户安装目录执行真实覆盖安装；差分传输比例取决于本机缓存和网络条件。
