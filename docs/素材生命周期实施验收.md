# 素材生命周期实施验收

状态：源码完成，未打包、安装或发布。

## 实现范围

- 素材目录与引用来源适配位于 `backend/static/media-runtime`；个人数据目录中保存独立登记数据库、事务及回收站归属信息。
- 画布及回收站、聊天与历史、资产库、工作流、Agent 和导入记录参与引用检查；画布当前状态、撤销及循环上下文通过会话保护同步。
- 原有直接删除入口统一检查引用并使用可恢复操作；历史删除只移除记录。共享资产条目的元数据可独立恢复，永久移除条目不删除仍被使用的文件。
- 数据存储页提供默认关闭的自动清理、30 天观察、默认 7 天回收站、扫描/取消、筛选分页、引用位置和手动保留。
- 保留先前迁移缓存占用修复，备份位于工作区 `.backups`，没有回退原有编辑。

## 实际通过

- Node 全套 80 项通过，无失败、无跳过。
- 随软件集成的 Python 3.10.11 全套 125 项通过，无失败、无跳过。
- 素材核心 27 项包括引用、别名、失联保护、文件身份替换、目录联接/硬链接、第二进程、回收站与移动恢复、共享配套文件、自动到期和跨页清理。
- 素材后端集成 14 项包括来源/操作验证、共享文件、条目恢复中断、独立条目恢复、重复 URL 批量删除及永久移除元数据时保留文件。
- 前端专项 12 项包括真实撤销函数、保护失败仍保存、恢复失败或编辑竞争不提交旧快照、成功保存后的关闭释放和快速编辑合并。
- 真实 Chromium + 隔离后端联动通过：设置默认关闭及开关保存、实际引用扫描、观察期、受引用文件不可选择、回收站移入与恢复、智能画布删除撤销、两种画布会话。
- 性能定点验证：32 MiB 已登记且未变化的视频扫描不再读全文件哈希；128 MiB 新文件扫描可以中途取消，期间其他线程可取得协调锁。
- 独立只读验收发现重复 URL 恢复遗漏后修复，独立复测确认两条独立回收记录、选择性恢复与另一条永久移除都不损坏共享文件。
- JavaScript 语法及 Git 差异空白检查通过。
