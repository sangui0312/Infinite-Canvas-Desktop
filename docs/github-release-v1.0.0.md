Infinite Canvas Desktop 正式版 1.0.0

智能画布新增 Agent 创作助手：在右下角缩略图上方打开，快捷键 Ctrl+Shift+A。引用素材并描述目标后，先检查计划和参数，批准后执行。

- 支持一套不同尺寸图片和视频的混合任务，图片可并发生成，任务恢复、成果定位与撤销保留手动画布修改。
- 模型、比例、分辨率、人设、并发与素材入口集中到底部输入框。
- 固定任务进度显示完成数量、整体百分比、当前任务及异常状态。
- 内置通用、电商、视频人设，可编辑提示词、新增人设及恢复默认；人设随个人数据保留，执行中的任务保持原版本。
- 电商套图分别规划主题、卖点和文案，避免连续多张重复细节展示。
- 待补充信息以独立问题卡片显示，支持快捷选项、逐项填写及分次补充；回复后重新规划，批准后才生成。

本次仅提供完整 Windows x64 安装包，不上传文件补丁。旧版本覆盖升级保留个人数据和自定义数据位置；安装过程不选择删除个人数据。

验证：52 项桌面测试、81 项后端测试通过；Agent 实际页面与本地后端联动的 20 张图片加 1 条视频模拟流程通过，包括补充问题、人设编辑、任务进度、交付及撤销。完整桌面包的启动、普通/智能画布交互、旧 Web 导入、数据存储和更新回滚检查通过。未调用付费模型，未验证真实生成质量或第三方上传服务。
