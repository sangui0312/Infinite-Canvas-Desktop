# Infinite Canvas Desktop 1.0.1 验证记录

## 发布范围

- 优化 3D 导演台的布局、对象编辑、关键帧、视角控制、撤销重做和 PNG/WebM 导出。
- 删除 RunningHub、火山引擎的内置适配和专属界面、接口、连接器代码；保留历史成果和不可用平台的明确提示。
- 更新公告按版本分组，保留历史记录。
- 清理默认平台后允许删除最后一个自定义 API 平台，前后端均持久保存空配置。

## 更新兼容性

本版基础文件与 1.0.0 的差异包括 `desktop_entry.py`、Photoshop 连接器的三个文件和桌面更新测试脚本。旧文件更新器的白名单不包含连接器，不能通过普通文件补丁完成全部清理。因此使用 `tools/build_windows.ps1 -PrimaryBaseline 1.0.0 -RequireFoundation` 构建，清单为 `mode: installer`，没有文件补丁附件。

安装包更新保留差分下载及失败时完整下载；不改变个人数据位置。基础文件兼容的同主版本更新继续按已有多基线补丁规则发布。归档本版 `release-tree.json` 为 `release-baselines/release-tree-1.0.1.json`，供后续版本比较。

## 实际通过

- 64 项 Node 检查、84 项 Python 检查全部通过，无跳过。
- 打包资源检查：30 项必需资源与源码字节一致，3332 个文件中未发现私有目录、环境密钥、缓存和日志；只读 Web 来源的 152 个记录文件未改变。
- 完整桌面窗口启动及退出、沙箱和会话隔离、普通画布右键添加节点及连线、保存重开、智能画布保存、下载和侧栏布局检查通过。
- API 设置空白状态、自定义平台保存、删除最后一个平台及持久化、语言切换检查通过。
- 打包版旧 Web 导入、普通及智能画布迁入、素材读取、来源只读检查通过。
- 更新 UI、公告纯文本安全、下载进度和手动安装状态检查通过；合成文件更新的应用、健康失败回滚、删除旧文件及个人资料保持检查通过。
- PNG/视频上传、视频 Range 206、混合媒体 ZIP、PSD、画布导入和项目导出检查通过。
- 版本公告实际 Chromium 窗口检查通过：软件更新与侧栏、本地与远端公告、深色模式、390px 窗口和 HTML 注入防护。
- 以本版实际清单检查 1.0.0、0.3.7、0.3.0 客户端路由，均选择 1.0.1 安装包；差分下载开启，安装包大小和 SHA-512 与 latest.yml 一致，各处公告一致。
- 3D 导演台已在隔离后端和真实 Chromium WebGL/MediaRecorder 下验证：PNG 和可读取 WebM 均为 720×1280；缩放改变画面而不重复分配缓冲；对象撤销重做、关键帧拖动删除、播放、窄窗口、取消录制和关闭资源释放均通过。最终打包的导演台文件与该源码一致。

## 验证边界

所有测试使用独立测试数据；未修改用户正在使用的安装或个人资料，未调用付费生成服务。未在用户安装目录执行真实覆盖安装，未以真实缓存和 GitHub 网络测量安装包差分下载比例；实际差分传输不可用时由更新框架回退完整下载。

GitHub 使用草稿上传，公开前逐项核对远端附件的大小与 SHA-256。附件包括完整安装器、blockmap、latest.yml、hybrid-update.json、release-tree.json、SHA256SUMS.txt 和 FFmpeg 来源归档。
