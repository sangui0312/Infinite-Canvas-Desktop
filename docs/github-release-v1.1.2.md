## GPT-Image-2.6 Ext

- 接入 APIMart 的 Flare / Sunburst，提供六种质量、复杂度、最多 16 张参考图和当前开放的 1K。
- 在线生图、对话生图、普通画布、智能画布及 Agent 共用参数规则，适配尺寸逐轮计算，多张结果拆成独立单张任务。
- 增加 PNG / JPEG / WebP / SVG / GIF 输出，支持 SVG 编写模型及推理档位。SVG/GIF 使用文生图，GIF 使用自动比例。
- 保留 SVG 原文件及 GIF 动画，补齐安全预览、再次引用、下载和素材管理。
- 完善已有任务查询、结果复用和批量部分成功处理，修复项目与画布导入的修订号冲突。

## 下载和更新

- Windows x64 安装包为 `InfiniteCanvas-Desktop-1.1.2-x64.exe`。
- 在软件中检查更新，兼容的 1.1.0、1.1.1 分别下载匹配自身版本的功能更新包，SVG 渲染组件包含在包内。
- 其他基础版本使用安装包升级，个人数据和自定义数据位置保留。
- 更新后进入 API 设置拉取模型，将 `gpt-image-2.6-ext` 加入图片模型列表。

验证采用隔离数据、合成素材与模拟上游。真实账号的生成效果和计费以所用服务为准。
