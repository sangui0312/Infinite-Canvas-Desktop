# 桌面版更新记录

- 2026-10-14-01：新增独立 Windows 桌面窗口，内置 Python 和工具，独立保存用户数据。
- 2026-10-14-02：接通桌面启动、保存退出、下载、受控重启和业务更新恢复；拒绝不兼容的 Web 更新包。
- 2026-10-14-03：侧栏 API 设置、更多设置、服务器更新、更新公告改为上下等宽、等高、等间距排列。
- 2026-10-14-04：修正安装目录选择：浏览磁盘根目录时自动带上 Infinite Canvas 子文件夹，并处理静默安装的根目录参数。
- 2026-10-14-05：统一 API 设置页隐藏平台过滤与默认选中；无可见平台时显示推荐入口，清理旧详情并修正隐藏样式，防止 ModelScope 等配置再次露出。桌面版本升至 0.1.1，覆盖安装可切换新版运行副本并保留个人数据。
- 2026-10-15-06：修复普通画布右键菜单和连线创建节点使用已删除常量而失败的问题，继续禁止已停用独立节点创建；增加菜单添加、连线创建、快捷栏添加及保存重开交互验证。桌面版本 0.2.1。

原 Web 程序与服务器版本清单未改动。本目录公告独立于 Web 待发布公告。

- 2026-10-15-07：新增安装目录内个人资料、自定义路径和校验迁移，保留旧目录备份；按安装位置隔离运行副本，卸载可选择删除资料，默认及升级始终保留。桌面版本 0.2.2。

- 2026-10-15-08：新增“从旧 Web 导入”：输入旧端地址检测项目和画布，直接下载全部引用的本地素材，支持普通/智能画布、进度、去重、失败重试和明确部分导入；旧端只读，不迁移 API 密钥，不覆盖现有项目。桌面版本 0.3.0。
- 2026-10-15-09：新增 GitHub 混合更新清单与精确基线文件包；校验、备份后应用文件增删改，启动异常和中断可回滚。基础组件变更及基线不匹配时使用安装包，启用差分下载与完整下载回退；功能版本和基础版本独立记录。首次使用需安装完整 0.3.0。

- 2026-10-20-17：智能画布新增 Agent 创作助手，入口在右下角缩略图上方，Ctrl+Shift+A 开关；引用素材后先规划、再批准执行，复用现有 API 平台和模型。
- 2026-10-20-18：独立图片任务支持 1～4 路并发，按组循环最多 2 路，视频顺序执行；支持任务恢复、定位成果及撤销，保留手动画布修改。
- 2026-10-20-19：图片与视频分别使用各自模型和逐项参数，整套不同尺寸图片及视频可连续规划执行；不支持的参数明确提示。
- 2026-10-20-20：Agent 参数整合至底部输入框，模型、尺寸、人设、并发和引用素材菜单向上展开，兼容窄窗口与明暗主题。
- 2026-10-20-21：输入框上方新增固定任务进度，显示完成数量、整体百分比、当前任务和异常状态，可查看详情或停止后续任务。
- 2026-10-20-22：人设支持编辑、新增和内置默认恢复，保存在个人数据目录；任务使用人设版本快照，执行中不受修改影响。电商套图避免重复主题、卖点和文案。
- 2026-10-20-23：待补充条件改为独立问题卡片，支持快捷选择、逐项回答和分次补充；回复后重新规划，批准后才生成。

正式版 1.0.0：包含以上 Agent 功能及历次修复；本次仅发布完整安装包，不上传补丁，覆盖升级保留个人数据。
