# 桌面版更新日志

按版本号从新到旧分组，同一版本使用项目列表，不使用日期编号。

1.0.1
- 3D 导演台改为对象列表、预览和属性三栏布局，适配明暗主题与小窗口；修复视角缩放，增加旋转、平移、镜头取景范围和重置视角。
- 支持对象复制删除、白块尺寸编辑、走位与镜头关键帧轨道、拖动和删除关键帧，以及独立撤销重做和播放快捷键。
- PNG/WebM 导出增加进度、取消和编码器失败提示，录制期间隔离编辑与播放，关闭时释放录制和 3D 资源，兼容旧预演数据。
- 删除 RunningHub 与火山引擎的内置平台配置、专属接口和前端适配；旧配置不再注入模型列表，旧节点保留已保存成果，不会静默改用其他平台；支持删除最后一个自定义平台并返回空配置页。
- 更新公告按版本号分组展示，保留历史记录，移除日期编号；软件更新和侧栏公告使用同一份版本日志。
- 本次同时清理补丁白名单外的 Photoshop 连接器文件，使用安装包更新（优先尝试差分下载），保留个人数据与自定义存储位置。

1.0.0
- 智能画布新增 Agent 创作助手，入口在右下角缩略图上方，Ctrl+Shift+A 开关；引用素材后先规划、再批准执行，复用现有 API 平台和模型。
- 独立图片任务支持 1～4 路并发，按组循环最多 2 路，视频顺序执行；支持任务恢复、定位成果及撤销，保留手动画布修改。
- 图片与视频分别使用各自模型和逐项参数，整套不同尺寸图片及视频可连续规划执行；不支持的参数明确提示。
- Agent 参数整合至底部输入框，模型、尺寸、人设、并发和引用素材菜单向上展开，兼容窄窗口与明暗主题。
- 输入框上方新增固定任务进度，显示完成数量、整体百分比、当前任务和异常状态，可查看详情或停止后续任务。
- 人设支持编辑、新增和内置默认恢复，保存在个人数据目录；任务使用人设版本快照，执行中不受修改影响。电商套图避免重复主题、卖点和文案。
- 待补充条件改为独立问题卡片，支持快捷选择、逐项回答和分次补充；回复后重新规划，批准后才生成。
- 正式版仅发布完整安装包，不提供旧版本到 1.0.0 的文件补丁；覆盖升级保留个人数据和自定义数据位置。

0.3.7
- 移除桌面端 NAS 配置同步和旧更新服务器入口，保留本地配置与备份恢复；视频上传增加自建媒体网关、Litterbox、temp.sh 逐级降级，上传前校验视频，失败信息不包含凭据。

0.3.6
- 更新机制改为多基线补丁：非主版本更新一次发布会携带多个旧版本（0.3.2 起）的差异包，客户端自动选择匹配自己版本的那一份；仅主版本号变化（如 1.x→2.x）时使用完整安装包。两条更新路线都保留用户数据。

0.3.5
- 桌面版支持本地媒体网关配置：把 NAS 私有目录的 media_gateway.json（或同格式文件）复制到数据目录 userdata 下并重启，本地参考视频（MiniMax 等）会自动经自建媒体网关上传为公网地址。包含 0.3.4 的模型分类修复。

0.3.4
- 修复 API 设置“拉取模型”时 seedance 系列（如 seedance2.0）被识别为 LLM 的问题；视频模型关键字同时补充 vidu、pixverse、skyreels、wan3。重新拉取模型后即可按“视频”分类导入。

0.3.3
- 在线生图与 GPT 对话的模型设置不再显示 ModelScope；API 设置推荐面板只保留 APIMART，移除其余平台卡片与底部 Seedance 说明。本版本同时用于验证 0.3.2 之后的文件更新包流程。

0.3.2
- 修复功能文件更新无法通过校验的问题：启动时不再改写 static 页面文件（版本标记改为响应时注入），运行文件与发布基线保持逐字节一致。当前 0.3.0/0.3.1 需用一次完整安装包升级，之后恢复小的文件更新包。

0.3.1
- 修复“更多设置”展开区高度不足，导致“数据存储”和“从旧 Web 导入”入口被裁剪、无法看到的问题。

0.3.0
- 桌面更新支持功能文件包与安装包自动选择；文件包严格匹配起始版本、校验后应用并在失败时回滚；安装包启用差分下载与完整下载回退，区分功能版本与桌面基础版本。
- 新增从旧 Web 地址识别项目并直接导入普通/智能画布及素材，支持进度、失败重试和缺失明细；不会迁入 API 密钥或覆盖已有项目。

0.2.2
- 个人资料默认保存在软件文件夹，更多设置新增数据存储位置选择、迁移校验和旧目录备份；各安装位置使用独立运行文件；卸载时可选择删除当前个人资料，默认保留，在线升级始终保留。

0.2.1
- 修复普通画布右键菜单无法添加节点，以及从连线创建节点失败的问题；已停用的独立节点继续禁止创建。

0.2.0
- 桌面软件更新改为 GitHub Releases 完整版本。下载前可查看版本公告，下载并校验完成后由用户选择重启并安装。可从 GitHub Releases 下载完整安装包或历史版本。

0.1.1
- 统一 API 设置页隐藏平台过滤与默认选中；无可见平台时显示推荐入口，清理旧详情并修正隐藏样式，防止 ModelScope 等配置再次露出。桌面版本升至 0.1.1，覆盖安装可切换新版运行副本并保留个人数据。

0.1.0
- 新增独立 Windows 桌面窗口，内置 Python 和工具，独立保存用户数据。
- 接通桌面启动、保存退出、下载、受控重启和业务更新恢复；拒绝不兼容的 Web 更新包。
- 侧栏 API 设置、更多设置、服务器更新、更新公告改为上下等宽、等高、等间距排列。
- 修正安装目录选择：浏览磁盘根目录时自动带上 Infinite Canvas 子文件夹，并处理静默安装的根目录参数。
